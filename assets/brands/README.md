# Music service brand assets

Official SVG artwork, stored locally without modifications. Trademarks belong to their respective owners.

- Spotify: black RGB icon from https://developer.spotify.com/images/guidelines/design/2024-spotify-logo-icon.zip — https://developer.spotify.com/documentation/design
- Apple Music: small white icon from Apple's Apple Music Icon 2020 download (https://apple.co/am-icon-2020), linked by https://marketing.services.apple/apple-music-identity-guidelines
- Amazon Music: horizontal Entertainment Dark RGB logo from https://amazonmusic.box.com/s/8eswutew4d093jo7450682oj1qntlysz, linked by https://artists.amazonmusic.com/brand-guidelines

Button surfaces use service-inspired colors. The Apple button gradient is a custom UI treatment, not an official Apple badge. Logo aspect ratios are preserved.
